description: "TypeSafe AI's Jev is a new model type that takes text in but returns only floating-point confidence scores for yes/no, multiple-choice, and rating questions, rather than generating text. It's extremely cheap ($0.042/million input tokens, output free) and fast, making it well-suited for classification tasks like spam filtering, labeling, prioritization, and search reranking. The tradeoff is a deeper black box than regular LLMs: you get a number with no explanation, so bias auditing and structured evals become critical. The community has already spun up open-weight recreations (e.g., Kev on Qwen) and a JevBench benchmark within a week of launch."
