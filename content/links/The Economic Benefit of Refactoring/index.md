description: "Refactoring a large Rust codebase using agentic tools reduces token consumption by up to 83% for future changes, as agents read less code when files are split into smaller, focused modules. The experiment showed input tokens dropped from 159,564 to 27,360 after refactoring the data access layer, saving about $39.7 at Sonnet 5 pricing. Refactoring lowers future work cost by minimizing code duplication and improving agent readability, though output token production remains high due to complex changes. The process highlights that effective refactoring requires human guidance, as agents struggle with independent code generation and execution."
