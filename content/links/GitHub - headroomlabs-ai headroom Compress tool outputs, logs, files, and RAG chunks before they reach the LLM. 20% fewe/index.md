description: "Headroom is a local-first context compression layer that reduces LLM input tokens by 60–95% without sacrificing accuracy. It applies specialized algorithms to compress tool outputs, logs, RAG chunks, and code before they reach the model, while also offering optional output shaping to trim verbose responses. All compressed data remains fully reversible with originals cached locally for on-demand retrieval. The system integrates as a Python or TypeScript library, zero-code proxy, CLI wrapper for major coding agents, or MCP server featuring shared cross-agent memory."
