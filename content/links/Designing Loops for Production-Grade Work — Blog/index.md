description: "Coding agents can autonomously solve production-grade problems from scratch, but only when guided by a structured iterative loop rather than zero-shot prompting. Initial attempts work on small datasets but fail at scale due to memory limits, parallelization bottlenecks, and encoding edge cases that require repeated execute-diagnose-fix cycles. To design effective loops, specify goals as high-level outcomes and constraints instead of implementation details, leveraging the agent’s cross-domain expertise. Finally, verify progress using external harnesses and full-scale production data that the agent cannot modify or bypass."
