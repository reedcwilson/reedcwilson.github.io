description: "Claude Cowork's new \"Projects\" (a confusing name, unrelated to the old Projects feature) now runs both the model and the execution VM entirely in the cloud, each session in its own isolated sandbox that's destroyed when the session ends. This eliminates the local VM's battery, disk, and performance costs, lets work keep running when you close your laptop, and enables use from a phone. File access is still limited to folders you explicitly add to the session, same as before. The Cowork team acknowledges the change was under-documented and more surprising to users than intended."
