description: "Beads is a lightweight agent orchestration system that replaces fragile markdown plans with persistent memory and structured workflows to prevent coding agents from losing context across sessions. It solves the \"dementia problem\" of agents forgetting their plan after each ten-minute compaction by using a single, evolving plan file instead of dozens of decaying ones. The author abandoned Temporal for a simpler orchestrator due to over-engineering and realized that automating agent workflows is key to true productivity. Beads enables seamless long-horizon coding with one command: bd init."
